常见问题

QuickBooks Online 一定需要 QBO 吗？

不一定。QuickBooks Online 可以直接导入兼容的 CSV，请优先尝试原生导入功能。

我的财务文件会被上传吗？

不会。本工具在你的浏览器本地处理 CSV，不提供文件上传服务器接口。

QBO 一定可以使用吗？

不能保证。QBO 导出仅用于实验，未经实际金融机构连接验证。

隐私与使用限制

网页代码在你的浏览器本地处理数据；请留意可能读取页面内容的浏览器扩展。下载的文件保存在设备上。本站为独立实验产品，与 Intuit 或 QuickBooks 无合作或背书关系。初步测试请不要输入真实账户标识，使用前须检查所有结果。

问题反馈与帮助

发现程序错误、金额问题或说明不清楚？可以通过 GitHub Issues 反馈。反馈公开可见，需要 GitHub 账户。请勿提交真实银行流水、账号、API 密钥或其他个人财务信息。请使用模拟示例。
