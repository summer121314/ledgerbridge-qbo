FAQ

Do I need QBO for QuickBooks Online?

Not necessarily. QuickBooks Online can import compatible CSV files directly. Try its native import first.

Are my financial files uploaded?

No, this prototype processes CSV entirely in your browser. It does not use an upload endpoint.

Is QBO guaranteed to work?

No. This export is experimental and has not been verified with live financial institution connections.

Privacy and limitations

Files are processed locally by the current page code; avoid browser extensions that can read page content. Exported files remain on your device. Independent experimental product. Not endorsed or affiliated with Intuit or QuickBooks. Do not input real account identifiers for initial tests. Review every result before use.

Feedback & support

Found a bug, incorrect CSV amount or confusing instruction? Report it through our GitHub issue tracker. Reports are public and require a GitHub account. Never include real bank statements, account numbers, API keys, or other personal financial details. Use synthetic sample rows instead.
